# レミフェンタニル血中濃度計算機 (Mintoモデル)

このWebベースのツールは、Minto薬物動態モデルに基づき、患者のパラメータとレミフェンタニルの投与プロファイルから血漿中および効果部位の薬物濃度を推定します。

## 使い方

1.  `remi_cp_calc.html` ファイルをウェブブラウザで開きます。
2.  以下の患者情報を入力します：
    *   **年齢 (yr)**
    *   **性別**
    *   **身長 (cm)**
    *   **体重 (kg)**
    *   **計算刻み dt (s)**: シミュレーションの計算間隔（秒）。小さいほど精度が向上しますが、計算時間が増加します。
    *   **投与終了後 Z (min)**: 投与終了から何分後の濃度を計算するかを指定します。
3.  **ステップ投与（定速×区間）**セクションに、レミフェンタニルの投与スケジュールを入力します。
    *   各行に「投与速度(µg/kg/min), 継続時間(min)」の形式で入力します。
    *   例:
        ```
        0.2, 30
        0.1, 20
        0.3, 10
        ```
        これは、「0.2 µg/kg/min を 30分間投与した後、0.1 µg/kg/min を 20分間投与し、さらに 0.3 µg/kg/min を 10分間投与する」ことを意味します。
4.  **「計算」ボタン**をクリックします。
5.  結果が「血漿中濃度」と「効果部位濃度」としてng/mL単位で表示されます。

## モデル詳細

この計算機は、以下のMintoモデルのパラメータを使用しています。

*   **除脂肪体重 (Lean Body Mass, LBM)**: JamesのLBM計算式に基づいています。
    *   男性: `1.10 * 体重(kg) - 128 * (体重(kg) / 身長(cm))^2`
    *   女性: `1.07 * 体重(kg) - 148 * (体重(kg) / 身長(cm))^2`
*   **Minto 3-コンパートメントモデル**: レミフェンタニルの薬物動態を記述するモデルです。
    *   参照: Minto, C. F., et al. "Pharmacokinetics and pharmacodynamics of remifentanil in patients undergoing elective intracranial surgery." Anesthesiology 86.1 (1997): 10-23.
*   **計算方法**: 投与期間中および投与停止後の薬物濃度を、Runge-Kutta 4次法（RK4）を用いた数値積分により秒単位でシミュレーションしています。
*   **単位**: 血漿中濃度および効果部位濃度はナノグラム/ミリリットル (ng/mL) で表示されます。
